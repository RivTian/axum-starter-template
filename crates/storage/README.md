# {{crate_prefix}}-storage

存储门面：`Db`（开池 / 迁移 / 关池）。**骨架里没有任何表、没有任何仓储。**

## 边界

- 只有一件事：把 SQLite 连接池开对、迁移跑对、关池关对。
- 不预建表、不预放仓储、不做双后端抽象（骨架的引擎事实是 SQLite；换引擎是项目决策，README 记了步骤）。
- 编译期嵌入迁移（`sqlx::migrate!`）：部署不需要额外搬 `.sql`；迁移集为空，靠 `migrations/README.md` 占位。

## 目录

- `src/db.rs`：`Db` 门面（开池 / 迁移 / 关池）。
- `migrations/`：SQL 迁移目录（骨架为空，命名与纪律见目录里的 README）。
- `tests/db.rs`：开池、迁移记账、`PRAGMA busy_timeout`、关池、非法 scheme 的报错。

## 关键决策

- **关闭所有权明确**：装配层持有 `Db`，并把 `Db::close()` 注册为 supervisor 的**最后一个**资源关闭器
  （任务全部收尾之后才关池）。顺序错了会看到"关停中途连接被掐断"的报错，所以这条写进 README 而不是靠记忆。
- **错误消息不带连接串**：连接串可能含凭据，错误里只保留原因链与"哪一项配置"。
- **迁移失败即拒启动**：迁移在提交点之前跑，失败退出码 2——不带半套 schema 提供服务。
- **只支持 `sqlite:`**：别的 scheme 明确报错（`Db::open`），不做"看起来支持"的抽象。
